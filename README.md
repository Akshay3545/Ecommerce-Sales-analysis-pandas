# Ecommerce-Sales-analysis-pandas
# E-Commerce Sales Data Analysis using Python

This project focuses on analyzing an E-Commerce sales dataset using Python, NumPy, Pandas, Matplotlib, and Seaborn to extract meaningful business insights from customer, order, product, and sales data.

The dataset contains information such as Customer ID, Name, Gender, Order Date, Order ID, Product Category, Age, Age Group, State, Zone, Quantity, Amount, Payment Mode, and Delivery Days.

Key Analysis Performed

- Analyzed sales amount across different product categories.
- Compared Age Groups with Gender to understand customer distribution.
- Analyzed State-wise and Product Category-wise sales patterns.
- Compared Product Categories and States based on total sales amount.
- Studied quantity purchased across different product categories.
- Analyzed payment modes such as Cash, Card, and Wallet.
- Explored customer demographics, including Gender and Age Groups.
- Analyzed delivery days to understand order delivery patterns.
- Examined regional sales performance across different Zones and States.
- Created visualizations using Bar Charts and other graphical representations to make the insights easier to understand.

Technologies & Libraries

- Python
- NumPy – numerical operations
- Pandas – data cleaning, manipulation and analysis
- Matplotlib – data visualization
- Seaborn – statistical visualization

Objective

The main objective of this project is to transform raw E-Commerce sales data into meaningful insights that can help understand customer behavior, product performance, regional sales, purchasing patterns, payment preferences, and overall business trends.
